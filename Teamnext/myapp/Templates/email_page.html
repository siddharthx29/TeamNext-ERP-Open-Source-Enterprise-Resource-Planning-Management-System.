Inbound Email Webhook API Specification

External email services, transactional providers (Brevo, SendGrid Inbound Parse, Mailgun, Amazon SES), or custom background services can deliver emails directly into your TeamNext ERP inbox by sending an HTTP POST request.

Inbound Webhook Endpoint:
POST /api/email/receive/
JSON Payload Format: 
{
  "to": "{{ email|default:'user@teamnext.internal' }}",  // (Required) Your registered mailbox address
  "from": "client@external.com",                       // (Required) External sender email
  "subject": "Incoming Project Memo",                  // (Optional) Subject line
  "body": "Hello! Your external message arrived."      // (Required) Message body
}
cURL Test Snippet: 
curl -X POST http://127.0.0.1:8000/api/email/receive/ \
  -H "Content-Type: application/json" \
  -d '{
    "to": "{{ email|default:'user@teamnext.internal' }}",
    "from": "external-partner@example.com",
    "subject": "Test Inbound Dispatch",
    "body": "Hello from external email! TeamNext ERP inbound receiver confirmed."
  }'
